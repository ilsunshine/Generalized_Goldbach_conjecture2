# 酉 Möbius 函数的 Goldbach 型问题

[English](README.md) | [简体中文](README.zh-CN.md)

本仓库提供论文 **A Goldbach-Type Problem for the Unitary Möbius Function** 的英文版，研究酉 Möbius 函数在整数加法分解中的符号模式：当两个正整数之和固定时，它们不同素因子的结构如何影响符号组合及其出现次数。

**贡献者：田草林、杨晨曦。**

## 阅读论文

[A Goldbach-Type Problem for the Unitary Möbius Function（英文 PDF）](paper_english.pdf)

论文包含定义、定理陈述、证明、参考文献及有限验证说明。以下内容为论文主要结果的概述。

## 研究对象

本说明中的公式采用纯文本记号，无需数学渲染扩展即可阅读。规范排版的数学公式请参阅 PDF。

设 `omega(n)` 为正整数 `n` 的**不同素因子个数**，约定 `omega(1) = 0`，定义

```text
g(n) = (-1)^omega(n)
```

对整数 `N >= 2` 以及取自 `{-1, +1}` 的符号 `s, t`，用 `R(s, t; N)` 表示论文中的有序表示数 `R_st(N)`：

```text
R(s, t; N) = 满足以下全部条件的整数 a 的个数：
            1 <= a < N，g(a) = s，且 g(N-a) = t
```

研究的问题是：对于整数分解 `N = a + (N-a)`，四种符号模式是否都会出现，各自出现多少次？这里统计的是有序表示，交换两个加数通常得到不同的表示。

函数 `g` 是积性函数，但不是完全积性函数。它不同于按重数计算素因子的 Liouville 函数，也不同于在含平方素因子的整数上取零的普通 Möbius 函数。

## 主要结果

### 1. 对所有充分大整数的定量下界

论文证明：对所有充分大的整数 `N`，有

```text
R(-1, -1; N) >= N / (128 * (log N)^3)
R(+1, +1; N) >= N / (128 * (log N)^3)
R(-1, +1; N) = R(+1, -1; N) >= N / (64 * (log N)^3)
```

其中 `log` 为自然对数，`^` 表示乘方，`*` 表示乘法。论文没有给出这些定量下界起点的具体数值；下面的显式存在性结论由另一项定理给出。

### 2. 显式存在性与完整例外集合

对每个整数 `N >= 18`，四种有序符号模式均存在。对于整数 `N >= 2`，各模式表示数为零的完整例外集合如下：

| 符号模式 | 表示数为零的整数 N |
|---|---|
| `(-1, -1)` | 2, 3 |
| `(-1, +1)` 与 `(+1, -1)` | 2, 7 |
| `(+1, +1)` | 3, 4, 5, 6, 8, 9, 10, 14, 17 |

因此，四种模式共同的最优最终阈值为 18；负负、混合、正正模式各自的最优最终阈值分别为 4、8、18。这里的“最终阈值”指从该整数起始终存在相应表示，并不表示此前每个整数都是例外。

### 3. 几乎所有整数上的四分之一渐近式

论文证明，对几乎所有目标整数，有

```text
R(s, t; N) = N / 4 + o(N)
```

其中 `o(N)` 表示与 `N` 的比值趋于零的误差项。正文给出了更强的定量例外集估计。对于**每一个**充分大整数都成立的逐点四分之一渐近式，论文尚未证明。

### 4. 普通 Möbius 函数的相关问题

论文进一步讨论普通 Möbius 函数 `mu(n)`（取值为 `-1`、`0` 或 `+1`）所对应的九种加法符号模式，区分涉及零值模式的无条件估计，以及四种非零模式逐点渐近式所依赖的尚未解决的相关性问题。

## 方法与研究意义

证明结合算术恒等式与整数分解、均值和指数和估计、缺失符号模式的刚性、有限覆盖链及有限整数验证。显式存在性证明将 `N >= 100000` 的无限范围论证，与 `2 <= N < 100000` 的逐项核验分开处理，再合并得到完整分类。

本项目将乘法结构与加法表示问题联系起来：显式分类确定了全部小例外及精确的最终存在阈值，定量下界与几乎处处渐近式进一步描述了表示的丰富程度。研究同时说明，仅知道一个算术集合的密度，并不足以解决其加法表示问题。

本项目研究的是算术符号集合的 **Goldbach 型问题，并非经典哥德巴赫猜想的证明**；满足 `g(n) = -1` 的整数不一定是素数。
